# FoodieHub

FoodieHub is a full-stack online food ordering application that allows users to create an account, browse restaurants and menus, add items to a shopping cart, and place orders.

## Features

- User registration and login
- Restaurant and menu browsing
- Add and remove items from the shopping cart
- Checkout and order placement
- PostgreSQL database integration
- Docker-based local database setup
- Responsive user interface

## Tech Stack

### Frontend

- React 18
- JavaScript
- Ant Design
- HTML and CSS

### Backend

- Java 21
- Spring Boot
- Spring Data JDBC
- PostgreSQL
- Gradle
- Docker
